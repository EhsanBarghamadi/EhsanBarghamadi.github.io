Event Planet

API-first

An API-first event planning & management platform. Organizers create and run multi-stage events; participants browse, register, and give feedback — all through a fully documented REST API.

DjangoDRFPostgreSQL DockerJWTOpenAPI
  • State-machine event lifecycle (Draft → Published → Ongoing → Closed → Finished) with enforced transitions
  • EAV data model for type-safe, dynamic event attributes with no schema changes
  • JWT + session authentication, versioned endpoints, filtering & search
  • Dockerized with PostgreSQL, Swagger/Redoc docs, and a published Postman collection

Digichera

Marketplace

A multi-vendor e-commerce marketplace, in the spirit of Digikala or Basalam. Sellers open their own stores; customers shop across every store from one cart and checkout in a single flow.

DjangoPostgreSQLSQLite PillowBootstrap
  • One cart auto-splits into a separate order per vendor at checkout
  • Transaction-safe checkout with select_for_update() row locking to prevent stock issues under concurrent purchases
  • Phone-based auth with customer/seller/staff roles, plus guest-cart merging on login
  • Self-referential category tree with cycle protection and cascading soft-delete
